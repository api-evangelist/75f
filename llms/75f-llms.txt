# 75F

> 75F is an IoT-based building management and automation company (Burnsville, Minnesota; acquired by
> Carrier Global in July 2026). Its platform pairs wireless sensors, thermostats and Central Control
> Units with cloud software to control HVAC, lighting and equipment in commercial buildings. The
> developer surface is a Project Haystack-compliant REST API behind an Azure API Management gateway at
> api.75f.io, plus a v2 Special Schedules API. There is no public OpenAPI, no SDK, no MCP server and no
> event/webhook surface.

Generated by API Evangelist on 2026-09-05 from 75F's public developer documentation. This is a
third-party profile, not a 75F document. No 75F /llms.txt exists (probed 2026-09-05, 404).

## Access model

Two credentials on every call: a product-scoped `Ocp-Apim-Subscription-Key` (Azure APIM) and an
OAuth 2.0 client-credentials bearer token minted at https://api.75f.io/oauth/token from Facilisight
account credentials. The account must additionally hold the Facilisight **Secondary Manager** role on
every site being read or written. Requesting unauthorized points returns HTTP 200 with an empty
Haystack grid, not 403.

## APIs

- [75F Haystack API](https://support.75f.io/hc/en-us/articles/5459129016595-75F-External-API-s-Overview): Project Haystack 3.0 REST surface at https://api.75f.io/ph — read, hisReadMany, pointWrite, hisWriteMany. JSON or ZINC grids.
- [75F Special Schedules API](https://support.75f.io/hc/en-us/articles/45325600917651-Special-Schedules-Via-API): https://api.75f.io/v2/schedules/special — create, update and delete exception-based occupancy schedules. Scopes schedules:read, schedules:write.

## Operations

- [Read API](https://support.75f.io/hc/en-us/articles/5460066903827-Read-API): GET /ph/read?filter=<haystack-filter>[&limit=n], or by id list.
- [HisReadMany API](https://support.75f.io/hc/en-us/articles/5460179115923-HisReadMany-API): GET /ph/hisReadMany?ids=@id,@id&range=<range>. Range is start-inclusive, end-exclusive, in the point's own timezone.
- [PointWrite API](https://support.75f.io/hc/en-us/articles/6012128424851-PointWrite-API): POST /ph/rw/pointWrite. Returns the resulting Haystack priority array, not an empty grid.
- [HisWrite Many API](https://support.75f.io/hc/en-us/articles/6011449449619-HisWrite-Many-API): POST for writing timestamped values to multiple points.
- [Oauth API](https://support.75f.io/hc/en-us/articles/5459701361427-Oauth-API): POST /oauth/token, grant_type=client_credentials, expires_in 3600.

- Tridium Niagara driver

## What 75F does not publish

- No public OpenAPI. An OpenAPI 3.0 document exists behind the Facilisight API Trial and the APIM
  developer portal, but the anonymous portal API listing is empty and every public spec path on
  api.75f.io returns 404.
- No SDK or client library on any package registry.
- No webhooks, AsyncAPI, GraphQL or MCP server.
- No published rate limits, no 429 in the error reference, no RateLimit-* headers.
- No pricing page or API plan tiers — API Management is a contact-sales subscription add-on.
- No /.well-known documents and no A2A agent card on any host.
- No idempotency mechanism, no dry-run mode, no deprecation policy and no SLA.
